# Психея — демонстрация

Видео к предзащите кейс-чемпионата «Клинический компас». Клинический сценарий — назначение «Авиандра» (маритупирдин)
при генерализованном тревожном расстройстве: по ОХЛП это показание, по КР-457 — третья линия после неэффективности
антидепрессантов. Решение о назначении принимает врач. Данные тестовые, реальных пациентов нет.

Файлы — во вкладке **Releases**:

- `psyche-app-demo.mp4` — запись экрана работающего приложения с титрами (2:07): телефон пациентки и компьютер врача.
- `psyche-video-case.mp4` — видеокейс с озвучкой (4:26): полный путь врача и пациентки, предложения агента со ссылками на ОХЛП и КР.
